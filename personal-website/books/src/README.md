# AI Engineering Study Pathway: A Modern Roadmap

Welcome to the AI Engineering Study Pathway. As Artificial Intelligence transitions from research labs to production-grade applications, the role of the AI Engineer has emerged as a critical discipline. This roadmap provides a structured, hands-on guide to mastering the modern AI engineering stack, spanning foundational Large Language Model (LLM) techniques to complex agentic architectures and production MLOps.

This digital manual is organized into three core chapters:

## Table of Contents

- **[Chapter 1: Generative AI & RAG](./chapter_1.md)**: Explore the foundations of Generative AI, prompt engineering techniques, and Retrieval-Augmented Generation (RAG) architectures. Learn about vector databases like Chroma and Milvus, and data ingestion strategies.
- **[Chapter 2: Agentic Systems](./chapter_2.md)**: Move beyond static pipelines to dynamic AI agents. Learn about ReAct planning loops, reflection, tool calling with JSON schemas, function routing, and multi-agent frameworks like CrewAI and AutoGen.
- **[Chapter 3: MLOps, Fine-Tuning & Quantization](./chapter_3.md)**: Understand how to customize models and deploy them efficiently. Covers Parameter-Efficient Fine-Tuning (PEFT) using LoRA and QLoRA, model compression/quantization (FP8, AWQ, GGUF), and high-throughput inference engines like vLLM and Ollama.
